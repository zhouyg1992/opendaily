# 开源日报 · 2026-11-09 周一

> 今天这批项目透露出一个清晰信号：AI 正在从「能跑」走向「可控」。无论是设计系统、生成式 UI 还是浏览器代理，重点都不再是让模型自由发挥，而是用预定义组件、schema 和知识图谱给它划出边界。对创业者来说，机会不在再做一个更聪明的模型，而在做那层把不确定性收拢成可交付结果的约束层。

### AI / Agent 工具

* **[storytold/artcraft](https://github.com/storytold/artcraft)** — 面向艺术家和影视创作者的 AI 图像视频创作 IDE，先在 2D 构图、3D 摆场景，再选模型生成，强调可重复的精确结果。它解决的是纯提示词无法控制角色一致性和镜头的问题。

  > 灵感：适合切短视频和广告分镜这类需要角色一致性的垂直工作流，卖「可复现的镜头」而非「一次生成」；和通用文生图工具差在前期场景搭建。

* **[browser-use/browser-use](https://github.com/browser-use/browser-use)** — 开源浏览器代理库，可用任意 LLM 本地运行，也提供带隐身浏览器的托管云和 API，能像人一样填表、过验证码、完成预约。它解决的是网页自动化里反爬和登录态难题。

  > 灵感：适合做垂直行业的「代客操作」服务，比如签证预约、政务表单代填，按成功结果收费；与通用爬虫相比，它的价值在能处理交互和验证码。

### AI 基础设施 / 模型

* **[infiniflow/ragflow](https://github.com/infiniflow/ragflow)** — 从 RAG 引擎演进成「agent 原生数据库」的上下文基础设施，融合检索与 agent 能力，适配各种规模企业。它解决的是 agent 需要可靠、可管理的长期上下文的问题。

  > 灵感：适合做面向垂直行业的私有化知识底座，切法律、医疗等对数据合规敏感的客户；与通用向量库相比，它把检索流程和 agent 编排打包好了。

### 开发工具 / CLI

* **[googlecolab/google-colab-cli](https://github.com/googlecolab/google-colab-cli)** — Google Colab 的命令行工具，可在终端秒开 CPU、GPU、TPU 运行时，执行本地代码、管理远程文件、编排流水线，面向无头自动化和 agent 集成。它解决的是临时算力获取繁琐的问题。

  > 灵感：适合做面向小团队的「按需 GPU 任务队列」，切模型微调和批量推理场景；与自建集群相比，它把临时算力变成一条命令，降低试用门槛。

* **[HeyPuter/everything](https://github.com/HeyPuter/everything)** — 一个野心极大的单体仓库，试图从零重写并开源全世界的软件，从 Office、Slack 到 Photoshop、AutoCAD 都列在路线图里。它反映的是对专有软件订阅制的集体反弹。

  > 灵感：别把它当产品，当趋势信号看：开源替代专有软件的需求真实存在，机会在挑一个高频单点做深，而不是铺开做全家桶。

### 前端 / 设计

* **[meta/astryx](https://github.com/meta/astryx)** — Meta 内部用了八年的设计系统开源，150+ 无障碍组件，基于 React 19 和 StyleX，主打「人和 agent 一起构建」并自带 CLI。它解决的是 AI 生成界面时组件不统一、品牌失控的问题。

  > 灵感：可以围绕它做企业级主题定制与组件治理服务，切「让 agent 产出符合品牌规范」的场景；与裸用 Tailwind 相比，它自带约束和可访问性，省掉后期返工。

* **[vercel-labs/json-render](https://github.com/vercel-labs/json-render)** — 生成式 UI 框架，让 AI 从提示词生成界面，但只能使用你预先定义的组件目录，输出严格匹配 schema，支持流式渲染和 React、Vue、Svelte 等多端。它解决的是 AI 生成界面不可靠的问题。

  > 灵感：可以基于它做面向 SaaS 的「自然语言配置后台」，切运营人员改仪表盘、表单的场景；与让模型直接吐 HTML 相比，护栏让结果可预测、可维护。

### 数据 / 基础设施

* **[henrygd/beszel](https://github.com/henrygd/beszel)** — 轻量级服务器监控平台，带 Docker 统计、历史数据和告警，配置简单、开箱即用，支持多用户和 OAuth。它解决的是自建服务器和 homelab 用户不想上重型监控的问题。

  > 灵感：可以做成面向小型托管商的托管监控增值服务，切「替客户盯服务器」的场景；与 Prometheus 相比，它更轻、部署更快，适合资源有限的小团队。

### 安全 / 隐私

* **[MHSanaei/3x-ui](https://github.com/MHSanaei/3x-ui)** — Xray-core 的网页控制面板，支持 Vmess、Vless、Trojan、WireGuard 等多种协议，提供多语言界面和单机到多节点的部署管理。它解决的是自建代理配置复杂、多用户计费难的问题。

  > 灵感：适合做面向小团队的合规网络接入管理，切跨境办公和远程访问场景；与手写配置相比，面板把协议和流量计费可视化，降低运维门槛。

### Skill / 垂直工具

* **[xiaoyang111222/cn-math-taxonomy](https://github.com/xiaoyang111222/cn-math-taxonomy)** — 覆盖中小学数学、英语、物理的知识图谱，含上千知识点、先修边和题库，对齐课标，附自适应前置诊断，答错能沿先修关系回溯到具体薄弱点。它解决的是个性化学习缺乏结构化底座的问题。

  > 灵感：可以基于它做错题诊断和自适应练习产品，切家长愿意付费的提分场景；与题库类应用相比，先修图能定位到根因知识点，而不只是推同类题。
