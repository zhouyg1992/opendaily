**[2026.10.20 · 周二](daily/2026-10-20.md)** — 今天的项目有个共同信号：过去只有大公司用得起的专业能力——代码理解、金融建模、PDF 编辑、无线安全审计——正被做成能本地运行、能嵌进工作流的开源工具。机会未必在再做一个模型，而在把能力包装成垂直场景里开箱即用的产品。

#### AI / Agent 工具

**[Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify)** — 灵感：把「读懂遗留系统」做成迁移、审计场景的代码知识图谱服务，先切咨询和外包团队。

**[stablyai/orca](https://github.com/stablyai/orca)** — 灵感：Agent 工作台的机会不在再做一个 Agent，而在团队协作、成本控制和操作审计。

**[DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail)** — 灵感：把「让 Agent 少写代码」沉淀成团队规范插件，按仓库订阅，卖的是代码质量。

#### AI 基础设施 / 模型

**[shiyu-coder/Kronos](https://github.com/shiyu-coder/Kronos)** — 灵感：金融时序基础模型可切量化投研 SaaS，或给券商做私有化微调，数据与合规是壁垒。

#### 开发工具 / CLI

**[storytold/pdfcraft](https://github.com/storytold/pdfcraft)** — 灵感：本地 PDF 工作台可以切合同、病历、标书这类隐私敏感场景，做批注与 OCR 工作流。

#### 前端 / 设计

**[thesysdev/openui](https://github.com/thesysdev/openui)** — 灵感：生成式 UI 有机会成为 AI 应用的前端协议层，先切客服、报表和内部工具。

#### 数据 / 基础设施

**[bilawalsidhu/gods-eye-view](https://github.com/bilawalsidhu/gods-eye-view)** — 灵感：把公开地理数据做成记者、风控、保险用的实时情报面板，比通用地图更垂直。

#### 安全 / 隐私

**[martin-olivier/airgorah](https://github.com/martin-olivier/airgorah)** — 灵感：把 WiFi 安全自查做成面向中小企业的订阅服务或硬件盒子，替代昂贵的渗透测试。

**[Automattic/harper](https://github.com/Automattic/harper)** — 灵感：离线语法检查适合嵌进 IDE、邮件客户端和写作工具，按 SDK/API 收费，隐私是差异点。

#### Skill / 垂直工具

**[storytold/photocraft](https://github.com/storytold/photocraft)** — 灵感：本地专业修图仍有空位：切电商批量修图，或医疗、设计等不能上云的素材工作流。
