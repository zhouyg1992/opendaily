## [Nov 26, 2026 · Thu](daily/en/2026-11-26.md)

> Today's batch points to a shift: coding agents are moving from chat toys to long-running workers, and a support layer is forming around them, memory stores, headless browsers, skill packs, cost auditing.

### AI / Agents

* **[gastownhall/beads](https://github.com/gastownhall/beads)** — A persistent memory layer for coding agents: a distributed graph issue tracker built on Dolt that swaps messy markdown plans for dependency-aware task graphs,

  > Angle: Attack the context-loss problem in long agent runs by hosting the graph for teams. Sell visibility and rollback, not another agent loop.

* **[wshobson/agents](https://github.com/wshobson/agents)** — Write a plugin or skill once in Markdown, then let generators adapt it for Claude Code, Codex CLI, Cursor, Copilot and others, with validation and evals attached.

  > Angle: The compatibility layer is the business: an internal skill registry with versioning, permissions and evals, priced per seat. Stickier than any single skill.

* **[anthropics/claude-cookbooks](https://github.com/anthropics/claude-cookbooks)** — Anthropic's maintained notebook collection showing practical ways to use Claude, with copy-ready snippets and guides for common API patterns.

  > Angle: The fuller the official docs, the less room for third-party tutorials. The opening is packaging these patterns into deployable templates or internal…

### AI Infrastructure / Models

* **[lexmount/moli](https://github.com/lexmount/moli)** — A Rust headless browser built for AI agents, using on-demand layout and rendering to keep a full browser runtime at a light footprint.

  > Angle: Sell per-session economics to teams running heavy concurrent scraping. The wedge against Playwright is footprint,

* **[openvinotoolkit/openvino](https://github.com/openvinotoolkit/openvino)** — Intel's open toolkit for optimizing and deploying inference, accepting models from PyTorch, TensorFlow, ONNX and others across vision, speech, generative and language workloads.

  > Angle: This is infrastructure, not a product. The opening sits around it: helping enterprises move models from cloud to on-prem Intel boxes,

### Developer Tools / CLI

* **[ersinkoc/phonebox](https://github.com/ersinkoc/phonebox)** — Turns a spare Android phone into a desk panel and touch deck for Windows, Linux and macOS, with over a hundred widgets covering system stats, AI coding sessions and media control.

  > Angle: Classic reuse-old-hardware demand. Push it toward teams: aggregate build and agent status from many machines onto one wall display, and sell the aggregation,

### Frontend / Design

* **[ruffle-rs/ruffle](https://github.com/ruffle-rs/ruffle)** — A Flash Player emulator in Rust targeting both desktop and the web via WebAssembly, with solid ActionScript 1, 2 and 3 support.

  > Angle: The opening is content, not the player: bulk conversion and hosted archiving for legacy SWF assets, aimed at schools, museums and game publishers.

### Data / Infrastructure

* **[nginx/nginx](https://github.com/nginx/nginx)** — The official NGINX source repo covering web serving, reverse proxying, load balancing, API gateway and caching.

  > Angle: Do not compete with NGINX. Build config governance around it: turn scattered nginx.conf files into an auditable, rollback-friendly policy layer for ops teams.

* **[nats-io/nats-server](https://github.com/nats-io/nats-server)** — The CNCF high-performance messaging server that runs on cloud, on-prem, at the edge and even a Raspberry Pi, with over forty client implementations.

  > Angle: More a trend signal than a product opening. To ride it, build messaging observability for edge fleets so ops can see which agents and sensors keep dropping and…

### Vertical Tools / Skills

* **[vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills)** — Vercel's official skill pack for coding agents, bundling instructions and scripts into reusable capabilities, such as auditing a deployed project for cost,

  > Angle: Skill packs are becoming a new app-store surface. Build vertical packs per cloud or SaaS, and use the diagnostic report as a funnel into paid optimization work.
