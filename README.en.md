## [Nov 28, 2026 · Sat](daily/en/2026-11-28.md)

> Today's projects share one signal: AI is moving from conversation to execution. Agents now drive terminals, edit video software, generate real-world geography, and run at scale inside sandboxes.

### AI / Agents

* **[mastra-ai/mastra](https://github.com/mastra-ai/mastra)** — A TypeScript framework for AI apps and agents, covering model routing, workflows, evals and deployment, plugging into React, Next.js or Node, or running standalone.

  > Angle: Frontend teams often stall on backend orchestration. The angle is a template marketplace or hosted service that adds AI features to a Next.js project in one…

* **[wonderwhy-er/DesktopCommanderMCP](https://github.com/wonderwhy-er/DesktopCommanderMCP)** — An MCP server giving Claude and similar clients terminal control, filesystem search and diff-based editing, so AI can run commands,

  > Angle: For heavy AI-coding users boxed in by editor sandboxes. The angle is a safety and rollback layer for terminal actions that logs every command and supports…

### AI Infrastructure / Models

* **[agent-substrate/substrate](https://github.com/agent-substrate/substrate)** — A zero-trust sandbox runtime for agents on Kubernetes, claiming ten times container density, sub-500ms resume, and over 500 activations per second, with isolated compute,

  > Angle: This is infrastructure, not a product. The angle: host managed sandboxes for firms running untrusted agents at scale,

* **[gepa-ai/gepa](https://github.com/gepa-ai/gepa)** — Optimizes any text parameter, including prompts, code, agent architectures and configs, using LLM reflection plus Pareto-efficient evolutionary search.

  > Angle: For teams already running agents but stuck on quality. The angle is a continuous tuning service for prompts and agent configs,

* **[0xPlaygrounds/rig](https://github.com/0xPlaygrounds/rig)** — A Rust library for building modular LLM applications, shipping with a terminal coding agent built on it and extendable via Bevy plugins.

  > Angle: Fits embedding LLM capability into trading systems, edge devices or local servers. The angle is not another framework but a Rust-side adapter layer for model…

### Developer Tools / CLI

* **[NYLLON-SOFTWARE/SignuDoc](https://github.com/NYLLON-SOFTWARE/SignuDoc)** — A self-hosted e-signature platform: upload a PDF, place fields, send signing links, and keep a sealed copy with an audit certificate.

  > Angle: Aimed at small teams squeezed by per-seat e-signature fees. The opening is a vertical compliance edition for law firms or real estate,

* **[louis-e/arnis](https://github.com/louis-e/arnis)** — Generates any real-world location into Minecraft at high detail using OpenStreetMap and elevation data, supporting Java, Bedrock, Luanti and Hytale,

  > Angle: For education, urban planning and content creators. The angle is a lightweight digital-twin viewer that turns OSM data into walkable scenes for planning…

### Security / Privacy

* **[Hut-hzf/ung220z-tool](https://github.com/Hut-hzf/ung220z-tool)** — A credential self-check toolbox for fiber modems, with one-click extraction on UNG220Z and adapters for ZTE, FiberHome, Huawei and Unionman, plus firmware fingerprinting.

  > Angle: For installers and home-network tinkerers. The angle is a home network health check that bundles credential recovery,

### Vertical Tools / Skills

* **[samuelgursky/davinci-resolve-mcp](https://github.com/samuelgursky/davinci-resolve-mcp)** — An MCP server that lets AI assistants drive DaVinci Resolve through the official scripting API, covering editing, media pool, render setup, grading, Fusion and Fairlight,

  > Angle: Target small post-production shops and solo creators with high-frequency chores like batch-applying edit templates or auto-tagging footage.

* **[4lwayz/portwatch-vi](https://github.com/4lwayz/portwatch-vi)** — A static site tracking every community effort to bring GTA VI to PC, scoring each on one ladder with progress bars, milestones and blockers, refreshed every three hours.

  > Angle: The pattern is copyable: build progress trackers for any long-running community project and monetize with ads or merch.
