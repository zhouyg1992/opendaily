## [Nov 27, 2026 · Fri](daily/en/2026-11-27.md)

> Today's projects point to a shift: agents are moving from framework races to plumbing and deployment. Tool catalogs, sandboxes, phone control and review plugins make agents actually useful, while older engineering concerns like languages, fonts and desktop frameworks resurface.

### AI / Agents

* **[phone-harness/phone-harness](https://github.com/phone-harness/phone-harness)** — Lets agents like Claude Code or Codex drive a real phone: iPhone through the Mac mirroring window, Android over adb, with nothing installed or jailbroken on the device.

  > Angle: The clearest wedge is mobile automated testing and pre-release regression checks, still largely manual today.

* **[SWE-agent/mini-swe-agent](https://github.com/SWE-agent/mini-swe-agent)** — A hundred-line software engineering agent with no heavy config or monorepo that still scores above 74% on SWE-bench verified, used by Meta, NVIDIA and others.

  > Angle: A good starting point for teaching and internal tooling: customizing an issue-fixing workflow from these hundred lines beats adopting a framework.

* **[lsernau/grh-lean](https://github.com/lsernau/grh-lean)** — A Lean 4 proof of the Riemann Hypothesis and its generalization for Dirichlet L-functions, built on Mathlib with only three standard axioms,

  > Angle: The story is not whether mathematicians accept it, but that AI-assisted formalization now yields machine-checkable output.

### AI Infrastructure / Models

* **[superdesigndev/treg](https://github.com/superdesigndev/treg)** — A routing layer for agent tools rather than models: one base URL and token gives an agent access to thousands of pay-per-call APIs across SEO, social trends,

  > Angle: The real value is credential custody and metered billing, not the catalog. Target small teams sharing paid tools across agents and build usage splitting plus…

* **[TencentCloud/CubeSandbox](https://github.com/TencentCloud/CubeSandbox)** — Tencent Cloud's open-source sandbox for agents, built on RustVMM and KVM with hardware isolation and E2B SDK compatibility.

  > Angle: A drop-in alternative for the code-execution layer, especially for latency- and density-sensitive batch work.

### Developer Tools / CLI

* **[openai/codex-plugin-cc](https://github.com/openai/codex-plugin-cc)** — An official OpenAI plugin that lets Claude Code users call Codex for code review or hand off tasks, with read-only review, adversarial review and background job commands.

  > Angle: More signal than tool: vendors now accept that users won't stick to one agent. The opening is a cross-agent handoff and result-aggregation layer for teams…

* **[bendlang/bend](https://github.com/bendlang/bend)** — Bend 2 pitches itself as a language for communicating intent to AI: dependent types and proofs remove ambiguity,

  > Angle: Near term this is a signal, not a product. The tractable slice is formal verification of AI-generated code for correctness-sensitive finance and embedded…

* **[Marvisak/VIctory](https://github.com/Marvisak/VIctory)** — An attempt to run GTA VI's Xbox build natively on Windows: the game's x86-64 code runs unchanged inside the project's process while it supplies the platform layer and converts…

  > Angle: Technically a platform reimplementation with no near-term business path. The companion tracker site shows demand for waiting on console exclusives,

### Frontend / Design

* **[egoist/mygo](https://github.com/egoist/mygo)** — Desktop apps in Go where each window is either a page in the OS webview or a native UI drawn by the framework on the GPU,

  > Angle: It targets internal tools and always-on utilities, a niche Electron has over-served. The fit is background-resident,

* **[intel/intel-one-mono](https://github.com/intel/intel-one-mono)** — An open-source monospace family from Intel designed with Frere-Jones Type for low-vision and legally blind developers, covering over 200 Latin-script languages,

  > Angle: Not a startup, but it flags an underserved audience: accessibility as a differentiator for editors, terminals and IDE themes rather than a compliance checkbox.
