## [Nov 10, 2026 · Tue](daily/en/2026-11-10.md)

> Today's projects show AI moving from general chat interfaces into concrete workflows: stock analysis, CAD drafting, video editing, and 3D reconstruction are packaging model capabilities into deliverable products.

### AI / Agents

* **[garrytan/gbrain](https://github.com/garrytan/gbrain)** — An open-source project that gives existing agents controllable memory: it stores explicit facts with sources, supports corrections and withdrawal,

  > Angle: Auditable memory is the differentiator: every fact has a source and can be corrected. This suits a team knowledge-memory service for compliance-sensitive…

### AI Infrastructure / Models

* **[google-deepmind/mujoco](https://github.com/google-deepmind/mujoco)** — A general-purpose physics engine maintained by Google DeepMind, focused on multi-joint dynamics and contact simulation for robotics, biomechanics, and reinforcement learning.

  > Angle: Use it as the underlying engine for robotics or embodied-AI products rather than building an app directly.

* **[ooolabdev/ooosplat](https://github.com/ooolabdev/ooosplat)** — A local desktop app that turns ordinary or panoramic videos and image sequences into 3D Gaussian Splats in one click.

  > Angle: The bottleneck in 3D reconstruction is shifting from algorithms to workflow. Offer a shoot-to-interactive-3D-model service for real estate, artifacts,

* **[pyannote/pyannote-audio](https://github.com/pyannote/pyannote-audio)** — An open-source speaker diarization toolkit built on PyTorch, offering pretrained models for speech activity detection, speaker change detection, overlapped speech detection,

  > Angle: Diarization is a key middle layer for meeting and support-call analysis. Build a vertical conversation analytics product on top of it,

### Developer Tools / CLI

* **[anthropics/claude-code](https://github.com/anthropics/claude-code)** — Anthropic's agentic coding tool that lives in the terminal, understands your codebase, executes routine tasks, explains complex code,

  > Angle: For founders, it signals that the terminal is becoming the primary entry point for AI coding. The opportunity isn't cloning it but building around it:…

* **[HakanSeven12/OpenCADStudio](https://github.com/HakanSeven12/OpenCADStudio)** — An open-source CAD application built in Rust with 2D drafting and 3D modeling, native DWG/DXF read-write, a shared editing core across desktop and browser,

  > Angle: Native DWG read-write is scarce. The opportunity isn't general CAD but vertical lightweight viewing and annotation,

### Frontend / Design

* **[OpenCut-app/OpenCut](https://github.com/OpenCut-app/OpenCut)** — An open-source CapCut alternative aiming to cover web, desktop, and mobile video editing from one codebase. It is being rewritten with plans for a plugin architecture, MCP server,

  > Angle: The plugin ecosystem and automated rendering are gaps. A vertical template marketplace built on OpenCut's plugin API,

### Data / Infrastructure

* **[opengeos/GeoLibre](https://github.com/opengeos/GeoLibre)** — A lightweight, cloud-native GIS platform that runs in browsers, on desktop, mobile, and inside Jupyter. It ships 1,000+ WebAssembly geoprocessing tools for terrain, hydrology,

  > Angle: Professional GIS analysis in the browser bypasses the install and licensing of traditional desktop GIS.

### Security / Privacy

* **[GyulyVGC/sniffnet](https://github.com/GyulyVGC/sniffnet)** — A cross-platform network traffic monitor built in Rust with an intuitive GUI, IP geolocation, and protocol filtering.

  > Angle: Network checkups for non-security experts are an underrated scenario. Build anomaly alerts for homes or small teams on top of Sniffnet,

### Vertical Tools / Skills
